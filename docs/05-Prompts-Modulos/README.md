# 05 · Prompts Especializados dos Módulos

Um **prompt operável** para cada um dos 11 módulos do Career OS. Todos **herdam** o [System Prompt Master](../04-System-Prompt-Master.md) — não repetem os princípios globais (explicabilidade, rastreabilidade, usuário no controle); assumem-nos.

Cada prompt segue a mesma estrutura:
- **Papel** — quem o módulo é.
- **Entrada** — o que precisa para operar.
- **Método** — o passo a passo de raciocínio.
- **Saída** — o formato do resultado.
- **Guardrails** — os limites específicos do módulo.
